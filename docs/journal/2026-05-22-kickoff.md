# 2026-05-22 — Kickoff and scoping

First working session. Goal: scope out a standalone lawn-care advisory
app for a real Zeon Zoysia lawn in coastal South Carolina that
combines live conditions with a citation-grounded knowledge base.

## What we agreed

- **Phase 1 is lawn-only.** Future phases add live oaks (young +
  mature), palms, hydrangeas, and other shrubs. The repo leaves
  placeholder modules at `src/lawn_agents/subjects/{tree,shrub}.py`
  so the extension point is visible — but no premature abstraction
  until a second subject actually exists.
- **Direct Anthropic SDK**, not the Claude Agent SDK. Our pipeline is
  mostly deterministic; two LLM call sites (Sonnet for routing, Opus
  for synthesis) do not benefit from an agent loop. ADR 0001.
- **LanceDB + local `bge-small`** for the vector layer. Single-vendor
  (Anthropic only), zero per-query embedding cost, plenty good for a
  ~50-PDF corpus. ADR 0002.
- **Never guess on chemicals** — three-layer guardrail (prompt + schema
  + tests). Most important rule in the system. ADR 0003.
- **USDA-NRCS AWDB (SCAN)** for soil temperature, not GreenCast. The
  AWDB REST API is documented, federal-public-domain, exposes 2-inch
  and 4-inch sensors, and dodges the corporate-scraping legal/ToS
  worry that GreenCast would have introduced when this repo goes
  public. Fallback: Parton/Logan model from NWS air-temp history.
  ADR 0004.
- **Self-extending RAG via an allowlisted research subagent.** When
  retrieval is weak, the orchestrator searches a curated set of
  `.edu` / `.gov` / turf-industry domains, ingests new passages with
  `requires_review: true`, and asks the user to promote them via
  `lawn-agents review-additions`. ADR 0005.
- **Drought awareness** baked into annual planning. 2026 is a drought
  year in coastal SC; the planner pulls US Drought Monitor + NOAA CPC
  outlooks and emits conditional gates ("defer high-N if D2+ persists
  through May"). Becomes a built-in integration test.

## Why this matters

The lawn is real, the chemicals are real, and the marsh is fifty feet
away. The goal is decisions I can trust — not a chatbot that sounds
confident about Zoysia.

## Repo as artifact

This repo is also a blog post in progress. Engineering standards are
not optional:

- `src/` layout, `pyproject.toml` with `uv`, ruff lint+format, mypy
  `--strict`, pytest with coverage, pre-commit hooks, GitHub Actions
  CI on every push.
- ADRs in `docs/adr/` for non-obvious decisions.
- Engineering journal here (`docs/journal/`) — running notes, dead
  ends, rationale. This is the blog feedstock.
