# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its
code of conduct. The full text is published at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project — opening issues, opening pull
requests, or commenting — you agree to abide by its terms.

## Scope

This Code of Conduct applies to all project spaces: the repository,
issue tracker, pull requests, discussions, and any other forum
operated under this project.

## Reporting

Report unacceptable behavior to the maintainer via:

- **GitHub private vulnerability reporting** (preferred for anything
  sensitive): https://github.com/mattlawck/lawn-agents/security/advisories/new
- **GitHub direct message** to `@mattlawck`.

All reports are handled confidentially.

## Enforcement

The maintainer is responsible for clarifying and enforcing this Code
of Conduct and will take appropriate action in response to any
behavior they deem inappropriate, threatening, offensive, or harmful.

See the [Enforcement Guidelines][eg] in the canonical document for the
escalation ladder this project follows.

[eg]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines
